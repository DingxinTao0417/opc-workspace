# ADR-006：Harness 完整组件矩阵与自进化边界

- 状态：已接受（agent harness 能力扩展纵切实施）
- 日期：2026-09-03
- 对应任务：[harness 分阶段计划](../plans/agent-harness-phases.md)（F 阶段组）
- 明确授权：用户 2026-09-03 要求 harness 覆盖完整组件矩阵（系统提示与行为规则、工具、记忆与状态管理、执行环境、编排与规划、安全护栏、可观测性），并要求 agent 支持自进化、反思、纠错
- 与 ADR-004/005 的关系：继承全部安全边界；本 ADR 不赋予模型任何业务写能力、不引入代码/Shell 执行、不开放自主改写提示词或工具集
- 当前代码基线：app v0.1.0 / API v1 / SQLite schema 055 → 本纵切新增 056（ai_memories）

## 背景

ADR-005 交付了 harness 的最小运行时（LLMClient + 单层运行循环 + 工具注册表 + 预算），生产零工具。用户提出 harness 应覆盖业界标准组件矩阵，并具备自进化、反思、纠错能力。本 ADR 把该矩阵逐项映射到 opc 的安全边界内，定义可实施的能力与被拒方案。

## 决策

### 1. 纠错（工具失败自恢复）

- 工具执行失败不再直接终止运行：失败以结构化错误结果回填对话（`tool: error: ...`），模型可据此换参数重试或改变策略。
- 硬预算：单次运行内工具失败重试累计上限（默认 3 次），超限终止并返回已累积输出；错误不外泄密钥或堆栈细节。

### 2. 反思（agent 自发自评 + 静默修订，无用户开关）

- 反思是 agent 在处理任务过程中的**自发行为**：代码所有系统提示词要求模型在回答结束前自评草稿（含工具输出是否足以支撑结论），并在回复最末尾输出自评块 `[opc:selfcheck]{"sufficient":true}` 或 `[opc:selfcheck]{"sufficient":false,"note":"未满足之处"}`。
- harness 解析自评块并自主决策：充分 → 剥离自评块后输出草稿（单次调用）；不充分 → 自动触发一次静默修订轮，把模型自评的 note 作为数据回填到修订指令（代码所有模板）中，修订稿仅在非空且与草稿不同时替换。
- 自评块属于 harness 内部数据：无论何种路径（缺失、未闭合、JSON 非法）都防御性剥离，永不落库、永不展示；缺失/非法一律按充分处理。上限 1 次修订，杜绝循环放大；修订轮静默（不流式），流式 delta 中可能短暂出现的自评块由前端展示层过滤。
- 对外契约不变：`opc-ai-sse-v1` 不新增事件、聊天请求不新增参数——反思不可由用户开启或关闭，它始终在线。

### 3. 长期记忆与自进化（数据层进化，人工门禁）

- **形态**：模型识别到用户表达持久偏好/事实时，输出 `[opc:memory]{"content":"..."}[/opc:memory]` 建议块（系统提示词为代码常量，与任务块同机制）；前端解析为待确认卡片，用户确认后经 `POST /api/v1/ai/memories` 落地 `ai_memories`（056）。
- **注入**：后续会话由 ContextBuilder 注入已确认记忆（按更新时间取前 20 条、8 KiB 字节预算）作为系统上下文一部分（合并进 system 提示，协议适配器两侧一致）。
- **自进化的边界（硬约束）**：
  - 进化只发生在**数据层**（用户确认过的记忆事实）；系统提示词、工具集、代码行为永远代码所有，模型无权改写自身提示或注册工具。
  - 记忆写入必须经用户逐条确认；无自动写入路径。记忆用户可见、可删（设置区管理），不进业务导出面。
  - 注入有字节预算；记忆内容属操作态数据，不触发任务/项目/客户等业务模块。

### 4. 编排与子代理（仅设计，不实施）

- 任务分解/子代理依赖真实工具与更长运行循环，需在工具纵切之后独立评审；本 ADR 不实施。harness 的轮次预算与步骤记录（F3）为将来编排提供地基。

### 5. F3 运行追踪（设计就绪，随后续阶段实施）

- `ai_runs`/`ai_run_steps`（llm/tool/reflection 步骤、耗时、结果摘要）+ 会话内执行时间线 UI；本轮先落地纠错/反思/记忆，追踪表随后续阶段与工具数据一起交付，避免空表冒充能力。

## 被拒方案

- 把反思做成用户开关（`reflect` 请求参数）：用户 2026-09-03 明确纠正——反思与纠错是 agent 处理任务时的自发行为，不是用户可选项；已改为自发自评 + 自动修订。
- 模型自主改写系统提示/自我提示注入（prompt 自我进化）：破坏代码所有边界，拒绝；进化只走数据层记忆。
- 反思结果流式展示并允许连续多轮自辩：延迟与成本不可控，且 SSE 契约膨胀；采用静默单轮修订。
- 记忆自动写入（无确认）：违反"模型输出不可信预览、人工确认落地"原则。
- 记忆进业务导出：与 AI 表操作态/隐私边界冲突，排除。
- Docker/Shell 执行环境：ADR-003/004 已拒，不变。

## 验收闸门

- Harness 单元测试：纠错回填重试与超限、反思保留/替换/关闭、反思预算；`chatAI` reflect 参数契约测试（1 次 vs 2 次上游调用）。
- 记忆全链路：建议块解析（合法/非法/缺 content）、确认落地 API、列表/删除、注入预算、导出排除分类、前端卡片与管理测试。
- 全量回归（Go/Web/文档门禁）绿色；不提交代码。
