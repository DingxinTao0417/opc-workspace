# ADR-028：智能体模式的人工作业工作区

- 状态：已接受，Windows 原生验收与确定性门禁分开记录
- 日期：2026-09-17
- 范围：用户确认的右侧多标签、文件预览、Chromium、Git 审查、手动终端与侧边聊天；独立 AI 轨道。原人工作业区落地时不改变 schema 71；本次侧聊能力桥接在当前 schema 73 上同样不新增迁移或 API 版本。

## 决策

右侧从固定业务概览改为 `AgentWorkspace`。React/Zustand 拥有标签、分栏、草稿和短期目录标识；Rust 拥有目录授权、PTY 与浏览器进程资源。业务工作台不挂载这个面板。文件、Git、终端与浏览器内容不自动拼进提示词，也不会因打开面板或选择本地目录而成为 Harness 工具；H4-AM/H4-AN/H4-AO 是严格的显式快照例外：用户只能分别在已成功读取的 Git 审查、普通文本预览或已有输出的手动终端面板点击后，把有界副本暂存为待发送聊天文本，仍不产生工具权限。终端例外不含 PTY/root/路径/命令输入，只是最近的前端捕获输出尾部。H4-AP 最初在 `子智能体` 标签只读镜像当前主对话的计划汇总；后续补强允许同一只读计划响应的未替代步骤标题/状态和经验证的原建议、工作台记录入口，读取失败需显式提示。它不是本地工作区内容交接，也不能在右栏发送、授权、确认、执行或恢复，审批预览和产出正文仍留在原位置。

1. **目录读取**：只通过 `rfd` 原生目录选择器登记进程内 UUID。前端只传 root ID 与相对路径；Rust 拒绝绝对路径、父级跳转、ADS、符号链接及 Windows reparse point。普通文件预览有长度上限；HTML/SVG/Markdown 按转义源码显示，不能执行脚本。该授权不是针对恶意本地进程并发替换文件的 OS 沙箱。
2. **Git 只读**：仅选中的独立仓库根目录，要求 `.git` 在其内部；linked worktree 暂不支持。固定 `status/rev-parse/diff` 参数，禁用 optional locks、fsmonitor、external diff、textconv 和凭据提示；不接受命令字符串，不暂存、不提交、不推送。8 秒超时，单次输出 3 MiB 上限。
3. **手动终端**：只对 Windows 启用 `portable-pty` ConPTY + PowerShell，用户点击启动后才创建进程。禁用 PowerShell profile，使用 OS 环境白名单，不继承应用/模型/Sidecar 凭据环境；xterm 不装自动链接/剪贴板扩展。终端仍有当前用户的文件与网络权限，工作目录不是沙箱。Windows Job Object 使用 KILL_ON_JOB_CLOSE 管理准确进程树；无法登记 Job 时拒绝启动。最多 4 个终端，每个 1 MiB 内存输出环，单次读取 64 KiB，输入 16 KiB 上限，不写日志/数据库。H4-AO 只在用户点击后把 React 近期捕获输出的有界尾部暂存给聊天交接，二次带入并发送才外发；不读取滚动历史或输入缓冲，不含 PTY/root/路径，也不让模型写入终端。收起、换页保留；关闭终端标签确认后终止，应用退出时全部结束。
4. **主视图隔离**：所有新增 command 继续经过 `main` WebView caller guard。远程浏览器子视图无 capability、禁用 WebMessage，不能选文件、调用终端或访问 Sidecar。没有新增监听端口、持久凭据或远程 API。
5. **侧边聊天**：使用独立 session ID 与草稿，复用原有聊天控制器、SSE、取消/恢复与隐私策略。主会话和侧边聊天共用一次生成，侧边 stream owner 不切走主会话。默认只发送显式输入和既有会话/记忆上下文，不自动读文件、终端、Git 或浏览器内容。H4-AM 的 Git snapshot、H4-AN 的文本预览 snapshot 与 H4-AO 的终端输出 snapshot 都必须由用户在已读取的对应面板点击、在主/侧聊天的交接卡再次带入、再发送，才成为显式输入；不因标签或目录选择自动生成。文本预览快照不含 root ID 或路径，终端快照不含 PTY/root/路径或输入，二者均不是 `agent_files` 或终端授权。用户可在发送某一条侧边消息前显式选择现有工作台 scope；该单条 grant 才会注册对应业务查询/提议能力，发送接受后清除，不从主对话、上一轮或另一侧聊标签继承。保存会话的持久 assistant message 若产生工作台提议，确认卡挂在原侧聊消息下并逐项由用户确认或拒绝；主/侧同时显示同一 generation 时读取同一服务端 proposal/decision 状态，不复制审批事实。旧 `[opc:task]` 任务块与永久记忆建议仍需在主对话处理。关闭标签不是删除会话。
6. **生命周期**：标签/目录授权/终端不会跨应用重启恢复；浏览器 profile 按既有规则独立保存。前端隐藏原生网页时释放可见区域租约，关闭浏览器标签才销毁 WebView。分栏同一时刻最多一个 Chromium 原生可见区域。

## 与 ADR-003 的关系

本功能是用户手工操作的桌面工具，不是本地 Agent Adapter。ADR-003 的无任意 Shell、无任意路径、无网络工具约束继续适用于 Agent Runtime。模型不能请求启动终端、写入 PTY 或使用目录授权 ID；未来若引入自动执行，必须单独评审权限与隔离，不能复用这里的人工作业权限。

H5-E31 为浏览器留下一个窄例外：单消息独立授权后，模型只能提出后退、前进、刷新或停止当前标签的本地确认请求；可信主 WebView 在人点击后才调用原有 `browser_action`。它不把浏览器子视图、页面状态或标签身份交给模型，不开放 DOM/网络/下载/终端能力，仍不能复用本 ADR 的人工作业权限。

H5-G37/G38 为网页上下文增加另一个方向相反、完全由用户启动的窄例外：主 WebView 对当前活动 WebView2 标签运行固定、只读、限时的正文与可见链接提取；链接最多 20 条、合计 4 KiB，目标地址删除 query/fragment 并拒绝带凭据的目标。完整脱敏快照留在前端内存卡，经用户预览、再次带入和手动发送后才成为普通对话输入，不产生浏览器 scope。页面正文、链接文字和 URL 都是不可信外部内容，用户若之后要求导航，仍须单独授权并逐次确认；这不开放模型可调用的 DOM、点击、表单、网络或下载能力。

## 验证与限制

- 确定性测试覆盖目录路径拒绝、源码预览不执行、输出环上限、标签/分栏/关闭、文件/Git 错误，以及侧边会话输入隔离、单条工作台授权不继承和同一 generation 审批状态复用。
- 文件与 Git 差异前端最多渲染 10,000 行，超限明确提示；终端输入异步写入，等待队列上限 64 KiB，阻塞的输入不持有终端注册表锁，关闭进程仍可执行。
- Windows ConPTY/PowerShell 探针单独运行：`cargo test --manifest-path apps/desktop/src-tauri/Cargo.toml real_powershell_pty -- --ignored`。它只运行固定输出命令，不访问业务数据、不请求模型；默认门禁不依赖真实终端设备。
- Windows 桌面实测通过：原生目录选择、源码文件标签、Git 分支与差异、Chromium 加载公开测试页、浏览器/文件分栏、放大/还原、收起/重新打开保留标签。侧边聊天 UI、请求隔离、显式 grant 与就地审批使用确定性测试，不把真实模型回复质量算作已验收。
- 真实模型质量、安装包、macOS/Linux 终端进程树、第三方登录/浏览器扩展、Office/PDF 渲染、Git linked worktree、侧聊并行生成仍不是当前交付能力。
- 依赖一手接口：[portable-pty](https://docs.rs/portable-pty/0.9.0/portable_pty/)、[rfd](https://docs.rs/rfd/0.17.2/rfd/struct.AsyncFileDialog.html)、[xterm 插件接口](https://xtermjs.org/docs/guides/using-addons/)。
