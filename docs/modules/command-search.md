# 命令面板与全局搜索模块

> 文档状态：部分实现；v0.1 目标是建立本地统一搜索、实体详情直达和可靠的键盘工作流。

## 定位与边界

本模块提供两个彼此配合但职责不同的能力：

- 命令面板负责发现并执行当前可用的本地导航与操作。
- 全局搜索负责从 Sidecar 查询本地业务实体，并返回可定位的结果。

边界约束：

- 所有索引和查询完全在本机完成，不把关键词、实体标题或业务内容发送到线上服务。
- 搜索结果不是业务事实副本，只保存资源类型、ID、摘要和定位信息。
- 命令是否可执行必须依据模块是否已交付、当前权限和运行状态；不能展示无行为按钮。
- WebView 内快捷键与 OS 全局快捷键分层：当前 Ctrl/Cmd+K 和 Ctrl/Cmd+N 只在应用窗口获得焦点时有效；跨应用唤起归桌面平台。
- 命令执行仍调用对应模块 API，不能绕过任务状态、Agent 验收、发票确认或其他安全规则。

## 当前实现状态

当前命令面板已支持：

- Ctrl/Cmd+K 在当前 WebView 内打开命令面板。
- Ctrl/Cmd+N 打开新建任务弹窗。
- 页面导航：今日、收件箱、任务、项目、客户、收入、发票和专注。
- 操作：新建任务、打开设置。
- 对当前 useTasksQuery 已加载数据的前 12 条任务进行前端 substring 过滤。
- 上下方向键、Enter、Escape、鼠标 hover 和空结果反馈。

当前限制：

- 没有 GET /api/v1/search，搜索只覆盖固定第一页最多 100 项任务中的前 12 项。
- 不是模糊搜索，没有关键词高亮、最近使用或相关性排序。
- 任务结果只跳到任务列表，不打开、定位或高亮对应任务。
- 不搜索项目、客户、收件箱、发票或后续知识库。
- “专注设置”无法指定设置子模块。
- 页面骨架和未实现业务仍会出现在命令列表，可能暗示功能可用。
- 命令面板没有完整焦点圈闭与关闭后焦点恢复。
- AppShell 虽每 15 秒查询健康状态，但命令面板不展示服务不可用或恢复动作。
- 没有 OS 全局快捷键、快捷键冲突检测或自定义快捷键。

## 目标功能

### 统一命令注册

- 每条命令包含稳定 ID、标题、别名、类别、可用条件、快捷键、执行入口和风险级别。
- 页面命令、资源命令和操作命令使用统一展示结构。
- 模块未实现、资源状态不允许或 Sidecar 不健康时，命令隐藏或禁用并解释原因。
- 高风险操作只导航到确认界面，不在命令面板中无确认直接执行。
- 最近使用记录仅影响排序，不改变授权或状态校验。

### 本地全局搜索

- 通过 GET /api/v1/search?q= 查询已实现的 Task、Project、Client、Inbox Item；发票模块交付后再加入 Invoice。
- 结果至少包含 resource_type、resource_id、title、subtitle、matched_fields、route 和 updated_at。
- 服务端支持分页、类型筛选、稳定排序和最小查询长度。
- 第一阶段可用安全的规范化 LIKE 查询建立基线；数据量和相关性验证后再决定是否增加 SQLite FTS5。
- 输入采用参数化查询，限制长度和返回数量，避免通配符滥用与慢查询。
- 删除、归档或无权操作的资源不会返回可执行的陈旧命令。

### 资源详情直达

- 任务结果打开任务详情并定位 ID，而不是仅跳列表。
- 项目、客户、收件箱和发票结果打开对应详情。
- 路由可刷新、可复制，并在资源不存在时提供解释与返回入口。
- 从搜索启动专注时先确认任务和当前活动 Session。

### 键盘与可访问性

- Ctrl/Cmd+K 打开后输入框获得焦点，方向键移动，Enter 执行，Escape 关闭。
- 结果使用正确的 combobox / listbox 语义和活动项关联。
- 查询变化、加载、无结果和错误通过可访问状态反馈。
- 关闭后焦点回到原触发元素；背景内容不接收键盘。
- 输入法组合期间不错误执行快捷键。

### 最近使用与快捷操作

- 记录本地最近打开的资源和执行的安全命令。
- 空查询优先展示最近使用与高频入口。
- 支持新建任务、打开指定设置模块、开始专注和服务诊断。
- “生成发票”等操作只在对应 v0.4 模块交付且业务状态允许时出现。

## 关键用户流程

### 搜索并打开任务

1. 用户按 Ctrl/Cmd+K。
2. 面板立即显示本地固定命令和最近使用；输入框获得焦点。
3. 用户输入关键词，前端防抖调用本地搜索 API。
4. 结果按类型和相关性展示，并标明状态、项目或来源。
5. 用户选择任务，应用关闭面板并打开该任务详情。
6. 若任务已不存在，详情页显示资源不存在，不回退成错误的第一条任务。

### 执行安全快捷操作

1. 用户输入“新建任务”或“专注设置”。
2. 命令注册表检查 Sidecar、模块能力和当前弹窗状态。
3. 选择后打开对应弹窗或指定设置模块。
4. 操作的提交、校验和错误由目标模块负责。

### 搜索服务不可用

1. Sidecar 健康查询失败或搜索请求超时。
2. 面板仍可展示不依赖服务的页面导航。
3. 业务搜索区显示服务不可用、request ID 和重试入口。
4. 用户可进入诊断页或触发桌面服务恢复，不显示缓存结果为“最新”。

### 从系统全局快捷键唤起

1. 桌面平台捕获已注册且无冲突的 OS 全局快捷键。
2. Tauri 显示并聚焦主窗口，向 WebView 发出打开命令面板事件。
3. 命令面板按相同本地流程搜索与执行。
4. 平台不支持或授权失败时，设置页显示原因并保留 WebView 内快捷键。

## 数据/API/状态与事件

### 搜索 API

规划接口：

GET /api/v1/search?q=&types=&page=&page_size=

建议响应契约：

| 字段                        | 含义                       |
| --------------------------- | -------------------------- |
| resource_type / resource_id | 资源类型和稳定 ID          |
| title / subtitle            | 可展示摘要，不包含敏感全文 |
| matched_fields              | 命中的允许字段             |
| route                       | 应用内详情路由             |
| status                      | 用于判断可用操作的资源状态 |
| updated_at                  | 稳定排序和陈旧判断         |
| pagination                  | 页码、大小和是否还有下一页 |

当前 PRD 已锁定 GET /api/v1/search?q= 方向；具体 types 和分页参数在实现前通过 API 契约测试冻结。

### 命令状态

- idle：面板未打开或空查询。
- loading：本地搜索进行中，保留固定命令。
- success：展示搜索结果。
- empty：请求成功但没有匹配资源。
- error：搜索失败，展示重试和诊断，不伪造结果。

每条命令还具有 enabled / disabled 可用状态和 disabled_reason。

### 本地事件

- command_palette_opened / closed：仅用于本地 UI 协调，不写业务审计。
- command_executed：可用于本地最近使用；不记录完整查询正文或敏感参数。
- resource_opened：更新最近资源排序。
- desktop_shortcut_invoked：由 Tauri 发给 WebView。
- sidecar_state_changed：使依赖服务的命令即时启用或禁用。

最近使用可以作为非敏感 app_settings 子项或独立有上限的本地表；必须定义容量、清理和删除资源后的处理，不能无限增长。

## 与其他模块协作

- [任务](tasks.md)：任务搜索、详情直达、新建和开始专注；状态命令仍由 Task API校验。
- [项目](projects.md)、[客户](clients.md)：详情路由已交付；全局搜索 Provider 尚未接入。 [收件箱](inbox.md) 仍需在模块交付后注册 Provider 和详情路由。
- [财务与发票](finance-invoices.md)：v0.4 交付后才启用发票搜索与生成入口。
- [专注](focus.md)：选择任务启动专注，存在活动 Session 时先进入确认流程。
- [设置](settings.md)：打开指定设置模块，展示快捷键和搜索偏好。
- [桌面平台](desktop-platform.md)：负责 OS 全局快捷键、窗口显示和 Sidecar 状态事件。
- [知识库](knowledge-base.md)：后续本地全文检索可以复用搜索基础设施，但业务知识检索与导航搜索保持独立结果类型。

## 分阶段实施

### v0.1-A：命令注册与交互修正

- 将硬编码数组改为模块化命令注册表和可用条件。
- 增加指定设置模块、详情路由和未实现命令禁用逻辑。
- 完成焦点圈闭、关闭后恢复、输入法和键盘边界测试。

### v0.1-B：统一本地搜索

- 定义 SearchResult 契约和 GET /api/v1/search。
- 接入 Task、Project、Client 和 Inbox Item；只查询已经真实交付的模块。
- 增加分页、类型筛选、参数化查询、相关性与性能测试。
- 移除前端 slice(0, 12) 作为搜索事实的做法。

### v0.1-C：详情直达与健康反馈

- 为各实体建立稳定详情路由和不存在状态。
- 接入 Sidecar health/version，提供搜索重试和诊断入口。
- 记录有上限的最近使用，并处理资源删除与归档。

### 桌面与后续版本

- 桌面可靠性阶段接入 OS 全局快捷键和冲突诊断。
- v0.3 增加快捷键自定义。
- v0.4 加入发票与财务搜索；知识库交付后再增加知识来源结果。
- 在线搜索、远程建议和云端命令不属于当前阶段。

## 验收标准

- Ctrl/Cmd+K 和 Ctrl/Cmd+N 在当前 WebView 内可靠工作，不干扰文本输入和输入法组合。
- 命令面板可完全使用键盘操作，并在关闭后恢复触发元素焦点。
- 搜索不受任务第一页 100 项或前 12 项限制，能定位匹配的真实任务。
- Task、Project、Client 和 Inbox Item 只在对应模块交付后返回真实结果。
- 选择搜索结果打开指定资源详情，刷新路由仍能定位同一 ID。
- Sidecar 不可用时仍可导航本地页面，并明确显示搜索不可用与重试入口。
- 查询完全本地执行，日志和最近使用不保存完整敏感正文。
- 未实现、无权限或状态不允许的命令被隐藏或禁用并说明原因。
- 高风险操作不能从命令面板绕过确认、验收或权限检查。
- 参数化查询、输入长度、分页和性能边界有测试；特殊字符不会形成 SQL 注入。
- OS 全局快捷键只有在平台实际注册成功后才显示为可用。
- 搜索、空结果、错误、键盘导航和焦点行为通过真实浏览器验证。
