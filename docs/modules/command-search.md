# 命令面板与全局搜索模块

> 文档状态：核心本地搜索、详情直达、本地最近使用、设置运行诊断/诊断包/打开日志目录入口、Sidecar/Tauri 壳脱敏轮转日志、全局渲染错误恢复、包含白名单恢复/迁移进度的全局启动故障恢复页，以及命令面板/新建任务的 OS 全局快捷键已实现；启动前备份选择、其他全局动作和自定义快捷键仍待后续纵切。

## 定位与边界

本模块提供两个彼此配合但职责不同的能力：

- 命令面板负责发现并执行当前可用的本地导航与操作。
- 全局搜索负责从 Sidecar 查询本地业务实体，并返回可定位的结果。

边界约束：

- 所有索引和查询完全在本机完成，不把关键词、实体标题或业务内容发送到线上服务。
- 搜索结果不是业务事实副本，只保存资源类型、ID、摘要和定位信息。
- 命令是否可执行必须依据模块是否已交付、当前权限和运行状态；不能展示无行为按钮。
- WebView 内快捷键与 OS 全局快捷键分层：Ctrl/Cmd+K 和 Ctrl/Cmd+N 只在应用窗口获得焦点时有效；桌面另尝试注册 ⌘/Ctrl+Shift+K 和 ⌘/Ctrl+Shift+N，跨应用唤起时只显示/聚焦主窗口并发送固定 action。
- 命令执行仍调用对应模块 API，不能绕过任务状态、Agent 验收、发票确认或其他安全规则。

## 当前实现状态

当前命令面板已支持：

- Ctrl/Cmd+K 在当前 WebView 内打开命令面板。
- Ctrl/Cmd+N 打开新建任务弹窗。
- 桌面若注册成功，⌘/Ctrl+Shift+K 打开命令面板，⌘/Ctrl+Shift+N 打开新建任务；注册冲突、权限或平台失败只在运行诊断显示 `registered/unavailable`，并继续保留应用内快捷键。
- 页面导航：今日、收件箱、任务、项目、客户和专注；未交付业务的收入/发票不注册为可执行命令。
- 操作：新建任务、打开设置。
- 设置命令可直达个人资料、通用、外观、专注、人员与责任、数据与备份、运行诊断及关于模块。
- 输入 200 ms 后调用统一 `GET /api/v1/search`，一次搜索真实 Task、Project、Client 和活动 Inbox Item；命令面板读取首 12 条并通过稳定详情路由打开精确资源。
- 业务搜索具备加载、错误、重试和空结果反馈；页面与安全本地命令不依赖 Sidecar 搜索成功。
- Task 使用 `/tasks/:taskId`、Project 使用 `/projects/:projectId`、Client 使用 `/clients/:clientId`、Inbox 使用 `/inbox/:inboxItemId`；Task 与 Inbox 路由刷新后会恢复同一详情弹窗，不存在资源由详情查询明确报错。
- 空查询优先展示最近使用。浏览器/WebView 本地记录最多 8 条命令或资源身份，保留 90 天；记录只含命令 ID 或资源类型/ID，不保存搜索词、标题、摘要或业务正文。
- 面板打开时重新读取最近资源的本地详情；已删除资源确认返回 404 后自动清理记录，服务暂时不可用时保留记录但不伪造资源内容。
- 上下方向键、Enter、Escape、鼠标 hover 和空结果反馈；输入框使用 combobox/listbox 活动项关联。
- 命令面板和业务 `Modal` 都通过 portal 挂载到 `document.body`。打开时聚焦搜索框并锁定背景滚动，Tab/Shift+Tab 圈闭在面板内，关闭后恢复原触发元素焦点；二者共用一个 overlay stack，只有最上层响应 Escape/获得 `aria-modal`，下层进入 `inert`，叠层逐层关闭或父子同批卸载都不会提前释放滚动锁或把焦点留在已删除节点；输入法组合期间忽略执行和 WebView 全局快捷键。
- 完整路由/AppShell 由全局错误边界保护；渲染异常时使用不含原始错误的恢复页，可重新渲染、返回今日或打开位于边界外的运行诊断，路由变化自动复位。

当前限制：

- 第一阶段使用参数化 LIKE 基线，不是模糊搜索，也没有关键词高亮。
- 命令面板只读取统一搜索第一页 12 条；结果更多时需要继续输入关键词，API 本身支持稳定分页和类型筛选。
- 发票、财务和知识库不在当前搜索类型中，只有对应模块真实交付后才会注册。
- AppShell 虽每 15 秒查询健康状态，但命令面板不展示服务不可用或恢复动作。
- 没有开始/暂停专注、页面切换等 OS 全局快捷键、冲突细节或自定义快捷键。

## 目标功能

### 统一命令注册

- 每条命令包含稳定 ID、标题、别名、类别、可用条件、快捷键、执行入口和风险级别。
- 页面命令、资源命令和操作命令使用统一展示结构。
- 模块未实现、资源状态不允许或 Sidecar 不健康时，命令隐藏或禁用并解释原因。
- 高风险操作只导航到确认界面，不在命令面板中无确认直接执行。
- 最近使用记录仅影响排序，不改变授权或状态校验。

### 本地全局搜索

- 通过 `GET /api/v1/search?q=` 查询已实现的 Task、Project、Client、Inbox Item；发票模块交付后再加入 Invoice。
- 结果至少包含 resource_type、resource_id、title、subtitle、matched_fields、route 和 updated_at。
- 服务端支持分页、类型筛选、稳定排序和最小查询长度。
- 第一阶段可用安全的规范化 LIKE 查询建立基线；数据量和相关性验证后再决定是否增加 SQLite FTS5。
- 输入采用参数化查询，限制长度和返回数量，避免通配符滥用与慢查询。
- 删除、归档或无权操作的资源不会返回可执行的陈旧命令。

### 资源详情直达

- 任务结果打开任务详情并定位 ID，而不是仅跳列表。
- 项目、客户、收件箱和发票结果打开对应详情。
- 路由可刷新、可复制，并在资源不存在时提供解释与返回入口。
- 从搜索启动专注时先确认任务和当前活动 Session。

### 键盘与可访问性

- Ctrl/Cmd+K 打开后输入框获得焦点，方向键移动，Enter 执行，Escape 关闭。
- 结果使用正确的 combobox / listbox 语义和活动项关联。
- 查询变化、加载、无结果和错误通过可访问状态反馈。
- 关闭后焦点回到原触发元素；背景内容不接收键盘。
- 输入法组合期间不错误执行快捷键。

### 最近使用与快捷操作

- 记录本地最近打开的资源和执行的安全命令。
- 空查询优先展示最近使用与高频入口。
- 支持新建任务、打开指定设置模块、开始专注和服务诊断。
- “生成发票”等操作只在对应 v0.4 模块交付且业务状态允许时出现。

## 关键用户流程

### 搜索并打开任务

1. 用户按 Ctrl/Cmd+K。
2. 面板立即显示本地固定命令和最近使用；输入框获得焦点。
3. 用户输入关键词，前端防抖调用本地搜索 API。
4. 结果按类型和相关性展示，并标明状态、项目或来源。
5. 用户选择任务，应用关闭面板并打开该任务详情。
6. 若任务已不存在，详情页显示资源不存在，不回退成错误的第一条任务。

### 执行安全快捷操作

1. 用户输入“新建任务”或“打开设置”。
2. 命令注册表检查 Sidecar、模块能力和当前弹窗状态。
3. 选择后打开对应弹窗或指定设置模块。
4. 操作的提交、校验和错误由目标模块负责。

### 搜索服务不可用

1. Sidecar 健康查询失败或搜索请求超时。
2. 面板仍可展示不依赖服务的页面导航。
3. 业务搜索区显示服务不可用、request ID 和重试入口。
4. 用户可进入诊断页或触发桌面服务恢复，不显示缓存结果为“最新”。

### 从系统全局快捷键唤起

1. 桌面平台捕获已注册且无冲突的 OS 全局快捷键。
2. Tauri 显示并聚焦主窗口，向 WebView 发出打开命令面板事件。
3. 命令面板按相同本地流程搜索与执行。
4. 平台不支持或授权失败时，设置页显示原因并保留 WebView 内快捷键。

## 数据/API/状态与事件

### 搜索 API

当前接口：

GET /api/v1/search?q=&types=&page=&page_size=

响应契约：

| 字段                        | 含义                       |
| --------------------------- | -------------------------- |
| resource_type / resource_id | 资源类型和稳定 ID          |
| title / subtitle            | 可展示摘要，不包含敏感全文 |
| matched_fields              | 命中的允许字段             |
| route                       | 应用内详情路由             |
| status                      | 用于判断可用操作的资源状态 |
| updated_at                  | 稳定排序和陈旧判断         |
| `meta.page/page_size/total` | 稳定页码、大小和总数       |

`q` 去空格后必须非空且最多 200 个 Unicode 字符。`types` 可为逗号分隔值或重复参数，只接受 `task / project / client / inbox_item` 并按固定类型顺序去重；默认查询全部类型。`page` 默认 1，`page_size` 默认 20、最大 100。查询对 `%`、`_` 和反斜杠做 LIKE 转义并全程参数化。

相关性按“标题/名称精确匹配 → 标题/名称前缀 → 标题/名称包含 → 允许的次要字段包含”排序，再按更新时间倒序、资源类型和资源 ID 固定兜底。允许字段为 Task 标题/描述、Project 名称/描述、Client 名称/联系人/邮箱/电话、Inbox 标题/说明；响应显式返回 `matched_fields`。归档 Project 和 resolved/dismissed Inbox 不返回可执行结果，硬删除资源天然不在结果中。

### 命令状态

- idle：面板未打开或空查询。
- loading：本地搜索进行中，保留固定命令。
- success：展示搜索结果。
- empty：请求成功但没有匹配资源。
- error：搜索失败，展示重试和诊断，不伪造结果。

每条命令还具有 enabled / disabled 可用状态和 disabled_reason。

### 本地事件

- command_palette_opened / closed：仅用于本地 UI 协调，不写业务审计。
- command_executed：可用于本地最近使用；不记录完整查询正文或敏感参数。
- resource_opened：更新最近资源排序。
- desktop_shortcut_invoked：由 Tauri 发给 WebView。
- sidecar_state_changed：使依赖服务的命令即时启用或禁用。

已实现的最近使用为浏览器/WebView 本地键 `opc-command-recents-v1`：只记录 8 条最近命令 ID 或资源类型/ID，90 天后清理；空查询时在固定命令前展示。资源标题在展示前按当前本地 API 重新读取，确认 404 则删除记录，避免把已删资源作为可执行结果；不保存搜索词、标题、摘要或正文。

## 与其他模块协作

- [任务](tasks.md)：任务搜索、详情直达、新建和开始专注；状态命令仍由 Task API校验。
- [项目](projects.md)、[客户](clients.md)、[收件箱](inbox.md)：均已接入统一搜索和精确详情路由；归档 Project 与终态 Inbox 不产生陈旧搜索命令。
- [财务与发票](finance-invoices.md)：v0.4 交付后才启用发票搜索与生成入口。
- [专注](focus.md)：选择任务启动专注，存在活动 Session 时先进入确认流程。
- [设置](settings.md)：打开指定设置模块，展示快捷键和搜索偏好。
- [桌面平台](desktop-platform.md)：负责 OS 全局快捷键、窗口显示和 Sidecar 状态事件。
- [知识库](knowledge-base.md)：后续本地全文检索可以复用搜索基础设施，但业务知识检索与导航搜索保持独立结果类型。

## 验收标准

- Ctrl/Cmd+K 和 Ctrl/Cmd+N 在当前 WebView 内可靠工作，不干扰文本输入和输入法组合。
- 命令面板可完全使用键盘操作，并在关闭后恢复触发元素焦点。
- 搜索不受任务第一页 100 项或前 12 项限制，能定位匹配的真实任务。
- Task、Project、Client 和 Inbox Item 只返回真实、仍可打开的本地结果。
- 选择搜索结果打开指定资源详情，刷新路由仍能定位同一 ID。
- Sidecar 不可用时仍可导航本地页面，并明确显示搜索不可用与重试入口。
- 查询完全本地执行，日志和最近使用不保存完整敏感正文。
- 未实现、无权限或状态不允许的命令被隐藏或禁用并说明原因。
- 高风险操作不能从命令面板绕过确认、验收或权限检查。
- 参数化查询、输入长度、分页和性能边界有测试；特殊字符不会形成 SQL 注入。
- OS 全局快捷键只有在平台实际注册成功后才显示为可用。
- 搜索契约、空结果、错误、重试、键盘导航、焦点行为和稳定详情路由有自动化测试；真实浏览器/WebView 视觉与焦点仍需人工验收。
- 最近使用的容量、去重、过期、非敏感存储和 404 删除清理有自动化测试。
